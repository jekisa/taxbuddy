Fitur utama

Dibuat untuk workflow pajak yang berulang, detail, dan sensitif format.

01

Excel Mapping Otomatis

Simpan template mapping kolom untuk format Excel yang sering dipakai, lalu proses file berikutnya lebih cepat.

02

Export XML Coretax

Generate XML Coretax untuk Pajak Keluaran, Doc Lain Masukan, dan SPT Dokumen Lain dari satu workspace.

03

Database Lawan Transaksi

Kelola penjual, pembeli, pemasok, NPWP, alamat, diskon, dan default transaksi agar data konsisten.

04

Validasi Sebelum Export

Peringatan tanggal, data wajib, duplikat, dan field kosong membantu mengurangi revisi file.

05

Dashboard Riwayat

Lacak faktur yang sudah di-export ke XML sehingga tim punya jejak kerja yang jelas.

06

Responsive Workspace

UI modern dengan tabel TanStack, search, sorting, dan pagination untuk data besar.

Workflow

Upload, mapping, validasi, export.

  1. Upload ExcelAmbil file transaksi dari sistem penjualan atau pembelian.
  2. Apply TemplateGunakan mapping tersimpan untuk menekan pekerjaan manual.
  3. Review DataCek tabel, warning, database pembeli/pemasok, dan detail transaksi.
  4. Export CoretaxUnduh XLSX atau XML yang siap dipakai untuk pelaporan.

FAQ

Pertanyaan singkat sebelum mulai.

Apakah TaxBuddy menggantikan Coretax?

Tidak. TaxBuddy membantu menyiapkan data dan file export agar lebih siap digunakan di Coretax.

Apakah bisa dipakai untuk banyak format Excel?

Bisa. Template mapping membantu menyimpan format kolom yang berbeda untuk dipakai ulang.

Apakah data tersimpan?

Aplikasi ini punya database lokal untuk template, pembeli, penjual, pemasok, dan riwayat export.
